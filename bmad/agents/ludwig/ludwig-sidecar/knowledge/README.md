# Ludwig's Knowledge Base

This directory contains Ludwig's accumulated wisdom from orchestration battles.

## Contents

### war-stories.md

Battle scars from production orchestrations. Each story includes:

- What happened
- The disaster that followed
- The lesson learned
- The fix pattern with code

### patterns-catalog.md

Proven orchestration patterns that work:

- Architecture patterns (Orchestrator-Worker, Sequential, Parallel, Router, Evaluator)
- State management patterns
- Error handling patterns
- Integration patterns

### anti-patterns.md

Failure modes to avoid:

- Architecture anti-patterns
- State anti-patterns
- Error handling anti-patterns
- UX anti-patterns

### war-room-scenarios.md

Adversarial test cases organized by category:

- Edge inputs
- Service failures
- Race conditions
- Hostile users
- Scale pressure
- Time torture
- State corruption

## Contributing

After each significant engagement, Ludwig may propose additions via the `*reflect` command. New entries should follow the established formats in each file.

## Usage

Ludwig references these files during analysis and teaching. When explaining a problem, Ludwig will often say "Let me tell you about..." and reference a war story, or "This is called..." and reference an anti-pattern.
